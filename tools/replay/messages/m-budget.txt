fix(page): let the heading's size follow the viewport

The heading's size was fixed, so the budget inside it was the same size on a
phone as on a desktop and the number the reader came for was the smallest thing
on the page. It is `clamp(2rem, 7vw, 7rem)` now, with the line-height and the
letter-spacing that go with a display size, which measures 100.8px on a 1440
window and 32px on a 320 one.

The test is a reading of the token rather than of a rendering, because the
stylesheet is the thing that decides it and a screenshot of one window would
only prove that one window.

Read by running:

  python -m unittest tests.test_build_demo_page -v
