docs(adr): the decisions behind this pass, and the ones it reverses

Four decisions, and two of them reverse an ADR rather than adding to one.

ADR-0053 supersedes decision 2 of ADR-0040. The row carried the feed's own
ticket code -- SDR, 2AS, CDR -- in a column every reader scanned, and SDR is a
seller's vocabulary: a reader cannot tell from it whether a fare is restricted
and cannot act on it. The column is a word now, one of Advance, Restricted or
Regular, and the code is in the row's own disclosure. ADR-0040's other
decisions stand.

ADR-0055 amends ADR-0051. The separation between building and serving is kept;
the default is reversed. `python run.py` built one station, and a single-origin
build cannot render the heading's station control at all, so the first thing the
runner did by default was produce a page that could not do the one thing its
heading offers. It also had no way to notice a stale build, and a page from
before the last commit is a page from before the last commit.

ADR-0054 is the shortlist: one control for the page rather than twenty, drawn
where the action is. ADR-0056 is the station name in the heading becoming the
field you type into, which is what a control that cannot be typed into is
missing.

The README's "Run it" section follows the runner, and docs/open-work.md's
question 3 records the amendment rather than losing the answer it already had.
